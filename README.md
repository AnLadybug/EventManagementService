## Быстрый запуск

### Требования
* [.NET 10.0 SDK](https://microsoft.com) (или выше)

### Запуск локально
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/AnLadybug/EventManagementService
   ```
2. Перейдите в папку проекта:
   ```bash
   cd Ru.AnLadybug.EventManagement/Ru.AnLadybug.EventManagement
   ```
3. Восстановите зависимости и запустите проект:
   ```bash
   dotnet restore
   dotnet run
   ```
4. Откройте Swagger в браузере: `http://localhost:5201/swagger` (или по порту из вашего `launchSettings.json`).

## Краткая документация API

### Схемы данных (получаемые DTO)

#### 1. CreateEventDto (Создание события)
* `Title` (string, обязательное): Название события.
* `Description` (string, опционально): Описание.
* `StartAt` (DateTime?, обязательное): Дата начала (UTC).
* `EndAt` (DateTime?, обязательное): Дата окончания (UTC).
* *Валидация:* `EndAt` должно быть строго позже `StartAt`.

#### 2. UpdateEventDto (Обновление события)
* `Title` (string, обязательное): Новое название события.
* `Description` (string, опционально): Новое описание.
* `StartAt` (DateTime?, обязательное): Новая дата начала (UTC).
* `EndAt` (DateTime?, обязательное): Новая дата окончания (UTC).
* *Валидация:* `EndAt` должно быть строго позже `StartAt`.

### Схемы данных (возвратные DTO)

#### 1. EventDto (Информация о событии)
* `Id` (Guid): Сгенерированный идентификатор события.
* `Title` (string): Название события.
* `Description` (string): Описание.
* `StartAt` (DateTime): Дата начала (UTC).
* `EndAt` (DateTime): Дата окончания (UTC).

#### 1. PaginatedResultDto<TDto> (Постраничный результат выборки данных)
* `TotalCount` (int): Общее количество элементов, удовлетворяющих условиям запроса (без учета пагинации).
* `Items` (IReadOnlyCollection<TDto>): Коллекция элементов на текущей странице.
* `PageNumber` (int): Номер текущей страницы (начиная с 1). (1 по умолчанию)
* `PageSize` (DateTime): Максимальное количество элементов на одной странице (размер страницы). (1 по умолчанию)


### Эндпоинты

| Метод | Путь | Описание | Тело запроса | Возможные ответы (Код / Тип) |
| :--- | :--- | :--- | :--- | :--- |
| **GET** | `/api/events` |Получить постраничный список событий с возможностью фильтрации. | *Нет* | `200 OK` (`PaginatedResultDto<EventDto>`) |
| **GET** | `/api/events/{id:Guid}` | Получить событие по ID | *Нет* | `200 OK` (`EventDto`) <br> `404 NotFound` (`string`)|
| **POST** | `/api/events/` | Создать событие | `CreateEventDto` | `201 Created` (`EventDto`) <br> `400 BadRequest` (`ValidationProblemDetails`)|
| **PUT** | `/api/events/{id:Guid}` | Обновить событие | `UpdateEventDto` | `200 OK` (`EventDto`) <br> `404 NotFound` (`string`) <br> `400 BadRequest` (`ValidationProblemDetails`)|
| **DELETE**| `/api/events/{id:Guid}` | Удалить событие | *Нет* | `204 NoContent` <br> `404 NotFound` (`string`)|

#### Параметры фильтрации и пагинации (`GET /api/events`)

| Параметр | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `title` | `string?` | `null` | Поиск по подстроке в названии события (без учета регистра). |
| `from` | `DateTime?` | `null` | Минимальная дата начала события (`StartAt >= from`). |
| `to` | `DateTime?` | `null` | Максимальная дата окончания события (`EndAt <= to`). |
| `page` | `int?` | `1` | Номер запрашиваемой страницы. |
| `pageSize` | `int?` | `10` | Количество элементов на одной странице. |

## Формат ответа при ошибках
### Пример ответов

* **`400 Bad Request` (`ProblemDetails`)** — возвращается при ошибках валидации или некорректных параметрах запроса:

```json
{
  "type": "https://tools.ietf.org/html/rfc9110#section-15.5.1",
  "title": "One or more validation errors occurred.",
  "status": 400,
  "errors": {
    "EndAt": [
      "Дата и время окончания события должны быть строго позже начала события"
    ],
    "StartAt": [
      "Дата и время окончания события должны быть строго позже начала события"
    ]
  },
  "traceId": "00-8ee6133ba0903c22f4b32ef643479205-92c56886bce01731-00"
}
```
* **`404 Not Found` (`string`)** — возвращается в виде строки при обращении к событию с несуществующим `Guid`:

  ```json
  "Событие с идентификатором d3b07384-d113-4956-d5c1-e8d1a1215496 не найдено"
  ```

### Основные коды ответов

| HTTP-код | Описание | Когда возникает |
| :--- | :--- | :--- |
| **`400 Bad Request`** | Ошибка валидации данных | Некорректный формат данных или нарушение бизнес-правил (например, `EndAt < StartAt`). |
| **`400 Bad Request`** | Некорректный формат запроса | Отсуствие обязательного параметра в запросе. |
| **`404 Not Found`** | Ресурс не найден | Объект отсутствует в системе. |
| **`500 Internal Server Error`** | Внутренняя ошибка сервера | Непредвиденный сбой на стороне приложения. |
